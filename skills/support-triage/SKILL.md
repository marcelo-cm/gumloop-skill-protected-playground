# Support triage

Use this skill when User A provides a support report.

1. Summarize the observed problem in one sentence.
2. Read `references/severity-guide.md` and choose a provisional severity.
3. State the evidence for that choice.
4. List up to three missing facts that could change the assessment.
5. Suggest one concrete investigation step.

Use abstract names such as User A and Agent X. Keep observations separate from
possible causes. Do not claim that an issue is fixed without verification.

Do not send messages, change account access, or modify customer data unless
User A explicitly asks for that action.
